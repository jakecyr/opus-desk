# Code of conduct

Treat people with respect in issues, pull requests, reviews, and project discussions. Welcome newcomers, explain technical disagreements clearly, and give actionable feedback about the work.

Harassment, discrimination, threats, personal attacks, sexualized content, and sharing private information without permission are not acceptable. Do not post credentials or sensitive customer data.

Project maintainers may edit or remove harmful content and restrict participation when needed. Report concerns privately using the maintainer's contact options on [GitHub](https://github.com/jakecyr); use private vulnerability reporting for security issues. Reports will be handled with discretion. Maintainers are subject to these same expectations.
